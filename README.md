# NimbleTerminal Homebrew tap

[Homebrew](https://brew.sh) packages for [NimbleTerminal](https://github.com/NimbleTerminal).

## Install

With an up-to-date Homebrew:

```sh
brew tap NimbleTerminal/tap
brew install --cask NimbleTerminal/tap/PACKAGE
```

Replace `PACKAGE` with a cask name from `Casks/`. No packages have been
published to this tap yet. The GitHub repository is `NimbleTerminal/homebrew-tap`;
Homebrew shortens its name to `NimbleTerminal/tap`.

```sh
brew update
brew upgrade --cask NimbleTerminal/tap/PACKAGE
```
